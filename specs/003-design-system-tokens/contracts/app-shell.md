# Contract: アプリシェル(ヘッダーとナビゲーション)

**Date**: 2026-09-18 | **Feature**: [spec.md](../spec.md)

FR-016 に基づき、現在の素朴なテキストリンク並びを置き換えるアプリシェルの契約を定める。

## 構造

| 要素 | 要件 |
|---|---|
| ヘッダー | 画面上部に固定的な領域を持ち、アプリ名を表示する。面として本文領域と区別できる |
| ナビゲーション | 4画面(体重 / トレーニング / 歩数 / 食材)への移動手段を提供する |
| 本文領域 | 各画面の内容。ヘッダーとの境界が視覚的に判別できる |

## アクセシビリティ要件(原則I / FR-009 / SC-011)

1. ヘッダーとナビゲーション、本文はそれぞれ役割が支援技術に伝わる領域として提供する
   (ヘッダー領域、ナビゲーション領域、主要コンテンツ領域)。
2. ナビゲーションには、それが何のナビゲーションかを示す名前を与える。
3. **現在地**: 表示中の画面に対応する項目が、支援技術にも「現在のページ」として伝わり、
   かつ視覚的にも判別できる(色のみに依存しない)。
4. **キーボード操作**: キーボードのみで4画面すべてへ移動できる。フォーカスの可視表示を保つ。
5. アクセシビリティ自動検査の違反を0件に保つ。

## 表示要件

- 画面幅375pxで、ナビゲーション項目が横スクロールを発生させずに収まる(FR-011 / SC-008)。
- ナビゲーション項目のラベルは UIラベルのテキストスタイル(1行表示)を用い、折り返さない。

## 検証

- 現在地の項目が「現在のページ」として伝わる `[自動]`
- キーボードのみで4画面へ移動できる `[自動]`
- 幅375pxで横スクロールが発生しない `[手動]`(ブラウザ自動操作による通し確認)
- ヘッダーと本文が面として区別できる `[手動]`
