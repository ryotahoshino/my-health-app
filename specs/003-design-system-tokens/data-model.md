# Data Model: デザイントークンとテキストスタイル

**Date**: 2026-09-18 | **Feature**: [spec.md](./spec.md)

本フィーチャーは永続データを扱わない(FR-013)。ここでモデル化するのは、見た目を構成する
**トークンの階層構造**と、それを画面で使える形にした**テキストスタイル**である。

## 階層構造

```text
公式トークン(@digital-go-jp/design-tokens)     ← 一次ソース。値をここ以外で定義しない
        │  写像(加工せず参照)
        ▼
tokens.ts(プロジェクトのトークン層)            ← 公式値の再公開 + 余白スケールの自前定義
        │  合成
        ▼
textStyles.ts(テキストスタイル)                ← size + weight + lineHeight + letterSpacing の組
        │  組み立て
        ▼
theme.ts(MUIテーマ)                            ← コンポーネントが参照する唯一の入口
        │  参照のみ(生値の記述は禁止: FR-003)
        ▼
各コンポーネント
```

## エンティティ

### 1. カラートークン

| 項目 | 内容 |
|---|---|
| 出自 | 公式(primitive / semantic / neutral の3系統) |
| 例 | `color-primitive-blue-500`、`color-semantic-success-1`、`color-neutral-white` |
| 制約 | semantic を優先して参照する。primitive の直接参照はテーマ定義内に限る |
| 検証 | 文字と背景の組み合わせがコントラスト比 4.5:1(通常文字)/ 3:1(非テキスト)以上(FR-008) |

### 2. タイポグラフィトークン(個別プロパティ)

| 項目 | 内容 |
|---|---|
| 出自 | 公式(`font-size-*` / `font-weight-*` / `line-height-*`) |
| 制約 | 本文は 16px 以上、行高は 1.5 以上。見出しは本文より行高を狭める |
| 字間 | サイズに応じて 0 / 0.01em / 0.02em |

### 3. テキストスタイル(合成物・本プロジェクトで定義)

デジタル庁デザインシステムの区分(Standard / Dense / Oneline)に対応づけ、本アプリで必要な
役割のみを定義する。命名は公式体系(`Std-16N-175` = 区分-サイズ-太さ-行高)と対応づけて管理する。

| 役割 | 用途 | 対応する公式スタイルの区分 | 制約 |
|---|---|---|---|
| 画面見出し | 各画面のタイトル | Standard(Bold、行高を狭める) | 本文より明確に大きく・太い |
| 節見出し | 画面内のまとまりの見出し | Standard(Bold) | 画面見出しより小さく、本文より大きい |
| 本文 | 記録値・一覧の内容 | Standard(Normal、行高1.5以上) | 16px以上 |
| 補足 | 算出根拠・注記・空状態の説明 | Standard(Normal、本文より小さい) | 色を弱めてコントラスト比は維持 |
| UIラベル | ボタン・タブ・表の見出し | Oneline(行高100%、字間0.02em) | 折り返さない前提の1行表示 |

**状態遷移**: なし(静的な定義)。

### 4. 余白スケール(本プロジェクトで定義)

| 項目 | 内容 |
|---|---|
| 出自 | 自前定義(公式トークンに余白は存在しない。research #2) |
| 基準 | 8px |
| 段階 | 4 / 8 / 16 / 24 / 32 / 48 px |
| 制約 | 段階外の値を使わない(FR-007)。要素間・面の内側余白はいずれもこのスケールから選ぶ |

### 5. 面(サーフェス)トークン

| 項目 | 内容 |
|---|---|
| 構成要素 | 背景色(semantic) + 角丸(公式 `border-radius-*`) + 境界線 + elevation(公式 `elevation-1..8`) |
| 用途 | 情報のまとまりを1つの面として示す(FR-005)。入力領域と結果表示領域の分離(FR-006) |
| 制約 | 入れ子は2段までとし、深い入れ子で余白が過剰にならないようにする |

## 検証可能な不変条件

- **INV-1**: `tokens.ts` 以外のファイルに色コード・`px` 付き寸法のリテラルが存在しない(FR-003 / SC-005)。
- **INV-2**: テキストスタイルの本文は 16px 以上かつ行高 1.5 以上(FR-012)。
- **INV-3**: 余白は定義済みの6段階のいずれかに一致する(FR-007)。
- **INV-4**: 公式トークンの値を `tokens.ts` で書き換えていない(一次ソースの単一性、原則IV)。
